이번에는 PRD만 등록합니다. IA·기능별 명세·화면설계·공통 정책·과거 계승 명세는 아직 등록되지 않았습니다. PRD에 기능 이름이 등장하더라도 별도 기능 명세나 화면 문서를 등록·승인한 것으로 보지 않습니다.

## 적용 기준

`main`의 문서는 최신 승인본이고 열린 PR의 변경은 검토 중인 초안입니다. 개발·배포 완료와 구분합니다. 업데이트 종료 시에만 최종 문서 목록과 완료 태그를 확정합니다.
