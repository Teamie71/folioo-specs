# 직무 찾기 기능명세

- 원문: [Notion 직무 찾기](https://app.notion.com/p/1a366be5909b82818f3a01b2f2da4d84)
- 관련 문서: [화면 설명](screen-description.md) · [참고 데이터](feature-overview.md#참고-데이터)

## 1. 기능 개요

- **목적**
  - 경험, 포트폴리오가 없는 저학년(2\~3학년) 사용자 대상의 신규 유입용 진입 기능
  - 직무별 추천 경험을 제시하여 경험 정리로의 전환 유도
- **형태**
  - 총 소요 3분 이내의 직무 찾기 테스트
  - 전공 선택 → 흥미 유형 테스트 → 가치관 밸런스 게임 순서로 테스트 진행
  - 결과로 직무 1-3순위 및 기업 형태 1-2순위 제시

## 3. 점수 산출

### 3-1. 성향 벡터

- 문항별 점수 체계
  - 1-12번 문항: 성향 특성 당 2문항의 응답값(1-6)을 합산
  - 13-15번 문항: 응답값에 따라 두 성향 특성 가/감점

|  | 그렇다 | 그렇다 -1 | 그렇다 -2 | 그렇지 않다 -2 | 그렇지 않다 -1 | 그렇지 않다 |
| --- | --- | --- | --- | --- | --- | --- |
| 13 | 추진형 +5.5<br>탐구형 +0.5 | 추진형 +4.5<br>탐구형 +1.5 | 추진형 +3.5<br>탐구형 +2.5 | 추진형 +2.5<br>탐구형 +3.5 | 추진형 +1.5<br>탐구형 +4.5 | 추진형 +0.5<br>탐구형 +5.5 |
| 14 | 현장형 +5.5<br>공감형 +0.5 | 현장형 +4.5<br>공감형 +1.5 | 현장형 +3.5<br>공감형 +2.5 | 현장형 +2.5<br>공감형 +3.5 | 현장형 +1.5<br>공감형 +4.5 | 현장형 +0.5<br>공감형 +5.5 |
| 15 | 창작형 +5.5<br>체계형 +0.5 | 창작형 +4.5<br>체계형 +1.5 | 창작형 +3.5<br>체계형 +2.5 | 창작형 +2.5<br>체계형 +3.5 | 창작형 +1.5<br>체계형 +4.5 | 창작형 +0.5<br>체계형 +5.5 |

  - 성향 특성별로 3문항의 점수를 합산하여 평균값 도출
- 산출물: 6개 값의 벡터 (e.g. 탐구/사고 4.5, 연결/사람 5.0, 추진/관리 4.0, 체계/사무 2.0, 실행/사물 4.0, 창작/아이디어 5.0)

### 3-2. 가치관 순위 및 가중치

- **방식**
  - 이진 비교 삽입 정렬
  - 신규 가치 등장 시 기확정 서열의 중간 순위와 비교
  - 응답에 따라 비교 범위를 절반씩 축소하여 위치 확정
- **출제 규칙**
  - 직전 응답 결과에 따라 다음 대결 자동 결정
  - 추이적으로 확정된 조합 (e.g. A>B, B>C 확정 시 A>C)은 출제 생략
- **종료 조건**
  - 5개 가치의 완전한 서열 확정 (5-8문항 소요)
- **가중치 변환**
  - 1위=5점부터 5위=1점까지 차등 부여 후 합계(15)로 나누어 정규화
  - 산출물: 합이 1인 5개 가중치 (e.g. 워라밸 0.333, 성장 0.267, 안정 0.200, 보상 0.133, 인정 0.067)

### 4-2. 계산 대상 풀 결정

| 사용자 선택 | 계산 대상 |
| --- | --- |
| 전공과 관계없이 찾기 | 전체 |

| 전공 반영 + 한정형 계열 | 2-1의 해당 전공의 대상 직무만 |

### 4-3. 부분 점수 계산

| 항목 | 계산식 | 범위 |
| --- | --- | --- |
| 성향 매칭 | 사용자 성향 벡터와 직무 성향 배점의 코사인 유사도 | 0\~1 |
| 전공 가산 | 가산형 계열 선택 시, 해당 전공의 대상 직무에 한해 가산점 적용 | 0 / +0.2 |

**최종 점수 = 성향 매칭 × 0.8 + 전공 가산**

### 4-4. 순위 확정 규칙

1. 풀 내 직무를 최종 점수 내림차순 정렬
2. 상위부터 순차 3개 선정

## 5. 기업 형태 추천 로직

### 5-1. 사용자 가치관 벡터 산출

- 밸런스게임으로 확정된 가치관 순위를 ROC 가중치로 변환

| 순위 | 가중치 |
| --- | --- |
| 1위 | 0.457 |
| 2위 | 0.257 |
| 3위 | 0.157 |
| 4위 | 0.090 |
| 5위 | 0.040 |

- 각 가치관에 해당 순위의 가중치를 배정하여 사용자 가치관 벡터 `U` 생성

```txt
U = [워라밸, 보상, 안정, 네임밸류, 성장·주도권]
```

### 5-2. 적합도 계산

- 별도 배점표에서 기업 형태별 가치관 벡터 `C`를 불러옴

```txt
C = [워라밸, 보상, 안정, 네임밸류, 성장·주도권]
```

- 사용자 가치관 가중치와 기업 형태 배점의 가중합 계산

```txt
기업 형태 적합도 = Σ(사용자 가치관 가중치 × 기업 형태 배점) × 100
```

```txt
기업 형태 적합도 = (U · C) × 100
```

- 실제 계산에는 반올림 전 ROC 가중치 `[137/300, 77/300, 47/300, 27/300, 12/300]`를 사용자 순위에 따라 배정
- 기업 형태 배점 벡터는 별도로 정규화하지 않음

### 5-3. 추천 결과 확정

1. 모든 기업 형태의 적합도 계산
2. 적합도 내림차순 정렬
3. 적합도가 가장 높은 기업 형태 1개를 최종 추천
