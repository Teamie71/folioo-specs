# 기획 리뷰 기준

- 내부 정합성: 용어·수치·조건·권한·상태/분기의 모순
- 문서 간 정합성: PRD·IA·기능 명세·화면 설명·공통 정책·승인된 예외
- 누락: 입력 제약·오류·로딩·빈 상태·취소·재시도·미결정·수용 기준
- 화면 연결: 선택 버전·UI 요소 ID·원문 Section·잘못된 삭제/중복 참조
- 정책·UX: 텍스트·문서 구조에서 확인 가능한 안내·흐름·복구·운영 질문
- 근거: 실제 결정·출처·관련 문서·미기록 상태
- 변경 영향: 함께 검토할 기능·정책·문서·유지/폐기 연결

모순·확인 필요·개선 제안으로 구분합니다. 모순에는 양쪽 근거와 적용 범위가 같은 이유를 제시합니다. 과거와의 의도된 차이·승인된 예외는 모순으로 판단하지 않습니다. 현재 기능의 마지막 변경 업데이트가 과거여도 계승 문서일 수 있습니다.

읽지 못한 자료를 보고하고 검토 완전성을 추측하지 않습니다. 이유·수치를 만들지 않고 이미지 자동 분석은 수행하지 않습니다. 근거 미기록·AI 제안 미채택만으로 병합을 차단하지 않습니다.
